# 統一格式與處理規則

本文件依 `scripts/clean_sellout.py`（整理程式）和 `scripts/build_dashboard.py`（Dashboard）目前的實際做法撰寫。改了程式請一併更新本文件。

## 1. 統一格式（`data/processed/sellout_daily.csv`）

每列是一筆「通路 × 門市 × 日期 × 商品」的銷售。屈臣氏、康是美合併在同一個檔案。

| 欄位 | 意義 | 屈臣氏 | 康是美 |
|---|---|---|---|
| 通路 | 資料來自哪個通路 | `屈臣氏` | `康是美` |
| 門市 | 門市代碼，4 碼數字 | 有，例如 `0009` | 報表沒有門市，**空白** |
| 日期 | 銷售日期，`yyyy-MM-dd` | 有 | 有 |
| 條碼 | 國際條碼，跨通路比對同一商品用 | 原始檔直接提供 | 原始檔沒有，**由品號對照表補上**；對照表沒填就空白 |
| 通路品號 | 通路自己的商品編號 | 原始檔「貨號」 | 原始檔「品號」，保留開頭的 0（如 `002784`） |
| 品名 | 商品名稱 | 原始檔「品名」 | **以品號對照表的品名為準** |
| 通路分類 | 通路自己的商品分類 | 部門分類代碼，例如 `00060018` | 商品小分類，例如 `330801保濕修護` |
| 銷售數量 | 件數 | 原始值 | 原始值 |
| 銷售金額 | 金額（元） | 原始值，四捨五入到小數 2 位 | 原始檔「銷售淨額(含稅)」 |

### 檔案格式

- 編碼 UTF-8 含 BOM，用 Excel 開啟中文不會亂碼。
- 每個欄位都加雙引號。
- 數字是整數時不帶小數點（寫 `449`，不寫 `449.0`），有小數時最多 2 位、去掉尾端的 0（例如 `718.4`）。
- 退貨等**負數照原樣保留**，不刪除、不轉正。目前資料有 78 筆金額為負（屈臣氏 75 筆、康是美 3 筆）。
- 輸出順序：先屈臣氏（照原始檔順序），再康是美（依商品分組，每個商品內依日期排序）。

## 2. 屈臣氏欄位對應

**來源檔**：`data/raw` 裡檔名符合 `*明細*.xls*` 的檔案，必須剛好一個。

**讀取範圍**：
- 只讀 `DailySaleExcel (2)` 工作表，同檔其他工作表不讀。
- 第 3 列是欄位名稱，A～H 欄必須**依序剛好是**：貨號、門市、條碼、品名、銷售數量、銷售金額、日期、部門分類。只要不同，程式就停下來並列出實際欄位。
- 第 4 列起是資料，每列原樣轉成一筆，**不合併、不加總**。
- 「貨號」不是純數字的列（空白列、合計列）會跳過。

| 原始欄位（欄） | 統一欄位 | 轉換方式 |
|---|---|---|
| 貨號（A） | 通路品號 | 轉文字 |
| 門市（B） | 門市 | 純數字時左邊補 0 到 4 碼；不是純數字就原樣保留 |
| 條碼（C） | 條碼 | 轉文字；Excel 存成數字的轉回完整數字，不會變成科學記號 |
| 品名（D） | 品名 | 去掉前後空白 |
| 銷售數量（E） | 銷售數量 | 轉數字，空白算 0 |
| 銷售金額（F） | 銷售金額 | 轉數字，空白算 0，四捨五入到小數 2 位 |
| 日期（G） | 日期 | `yyyyMMdd` 轉成 `yyyy-MM-dd` |
| 部門分類（H） | 通路分類 | 轉文字，保留開頭的 0 |
| （無） | 通路 | 固定填 `屈臣氏` |

## 3. 康是美欄位對應

**來源檔**：`data/raw` 裡檔名符合 `康是美*.xls*` 的檔案，必須剛好一個。只讀第一個工作表。

原始報表是「商品 × 日期」的寬表格，程式把它轉成每列一筆「商品 × 日期」：

- **日期欄**：第 3 列從 H 欄開始，凡是寫成「2026年7月1日」格式（或是 Excel 日期）的欄位都視為一天。一個都找不到時程式會停下來。
- **指標**：A 欄有字的列，代表新一段指標的開始，往下沿用到下一個指標出現：
  - 以「銷售淨額」開頭（如「銷售淨額(含稅)」）：這一段的數字是**銷售金額**。
  - 以「銷售數量」開頭：這一段的數字是**銷售數量**。
  - A 欄出現其他文字時，程式會停下來。
- 同一批商品在金額段、數量段各出現一次，程式**用品號把兩段合併**成同一筆。
- 從第 4 列開始讀；品號（F 欄）空白的列跳過。

| 原始欄位（欄） | 統一欄位 | 轉換方式 |
|---|---|---|
| 指標（A） | — | 判斷該列是金額還是數量 |
| 商品大分類（B）、中分類（C） | — | 不使用 |
| 商品小分類（D） | 通路分類 | 只寫在每組第一列，空白時沿用上一個有值的小分類；取該品號**第一次出現**時的小分類 |
| 品名（E） | 品名 | 只在**新品號寫進對照表時**使用（見第 6 節）；輸出一律用對照表的品名 |
| 品號（F） | 通路品號 | 保留開頭的 0；若存成數字，依儲存格格式（如 `000000`）補回 0 |
| 資料最新日期（G） | — | 不使用 |
| H 欄起每一天 | 日期＋銷售金額／銷售數量 | 見下方規則 |
| （無） | 通路 | 固定填 `康是美` |
| （無） | 門市 | 空白 |
| （對照表） | 條碼 | 從 `康是美品號對照.csv` 取得 |

**每日數值的規則**：
- 儲存格空白：當天這個指標沒有值，不寫入。
- 只有金額或只有數量時，缺的那一個算 0。
- 當天金額和數量**都是 0（或都空白）**：不輸出這一筆。
- 同一個品號在同一段指標中重複出現時，後面的值會**蓋掉**前面的值，不會相加。

## 4. 日期處理規則

| 通路 | 原始格式 | 輸出 |
|---|---|---|
| 屈臣氏 | `20260508`（文字或數字，`yyyyMMdd`） | `2026-05-08` |
| 康是美 | 欄位標題「2026年7月1日」，或 Excel 日期 | `2026-07-01` |

- 屈臣氏日期不是有效的 `yyyyMMdd` 時，程式會出錯停止。
- **康是美最後一天不完整**：報表的「資料最新日期」當天只有部分資料（目前資料是 2026-08-03）。
  - `sellout_daily.csv` **仍保留**這一天。
  - Dashboard 產生時會**自動排除康是美資料中最新的那一天**，並在頁面上註明。

## 5. 金額處理規則

- 四捨五入到**小數 2 位**，採一般的「四捨五入」：尾數 5 一律進位，例如 `628.425 → 628.43`。
  - 程式用 `Decimal` 計算。Python 內建 `round()` 會因為浮點數誤差把 `1227.135` 捨成 `1227.13`，所以不使用。
- 康是美金額是原始檔的「銷售淨額(含稅)」。屈臣氏原始檔沒有註明是否含稅，程式照原始「銷售金額」取用。
- 空白算 0；負數（退貨、折讓）照原樣保留。
- 數量也套用同樣的輸出格式，但目前資料的數量都是整數。

## 6. 康是美品號對照表（`data/processed/康是美品號對照.csv`）

康是美報表沒有國際條碼，靠這張表把康是美品號對到條碼，才能和屈臣氏的同一個商品合併。

| 欄位 | 意義 |
|---|---|
| 品號 | 康是美品號 |
| 品名 | 輸出到 `sellout_daily.csv` 的品名（可手動修改） |
| 條碼 | 輸出到 `sellout_daily.csv` 的條碼（可手動填寫） |
| 配對方式 | `自動（品名相同）` 或 `待補`；只是紀錄，程式不讀 |

**更新規則**：
- 表內**已有的品號整列保留**，不會被覆蓋，手動改過的品名、條碼都會保留。原始檔已不再出現的品號也不會被刪除。
- **新品號**第一次出現時才加入：品名取原始檔，並嘗試自動配對條碼。

**自動配對條碼**：把康是美品名和屈臣氏品名都做以下正規化，**完全相同**才配對，否則條碼留空、標為「待補」：
1. 英文字母轉大寫。
2. 全形括號 `（）` 轉成半形 `()`。
3. 去掉 `DR.WU`（`DR`、可有可無的 `.`、任意空白、`WU`）。
4. 去掉所有空白。

屈臣氏有多個品名正規化後相同時，用原始檔中最後出現的那一筆的條碼。

## 7. 試用品、體驗包

**判斷方式**：品名以 `88-33` 或 `試)`（`試）`）開頭。目前對照表有 9 個康是美品號屬於這類（8 個 `88-33`、1 個 `試)`），屈臣氏沒有。

**整理程式（`sellout_daily.csv`）**：
- **照常輸出**，不刪除、不另外標記。
- 自動配對條碼時，正規化**保留** `88-33`、`試)` 前綴，所以不會和不帶前綴的正式商品品名相同，也就**不會自動配到正式商品的條碼**，避免試用品和正式商品合併計算。（程式不是把試用品排除在配對之外，而是靠前綴讓品名對不上。）
- 目前 9 個都是「待補」、條碼空白。要不要給條碼、要不要列入分析，由使用者決定；若在對照表填入條碼，就會和該條碼的商品合併。

**Dashboard**：
- 判斷規則相同（以 `sellout_daily.csv` 的品名判斷），在排行標「（試用）」、在商品明細標「試用」。
- 篩選列有「排除試用品、體驗包」勾選項，**預設不排除**。
- 有條碼的商品會跨通路合併；合併後只要其中一筆品名是試用品，整個商品就視為試用品。

## 8. 無品名品號

- **判斷方式**：康是美原始檔「品名」欄空白。
- **處理**：新品號加入對照表時，品名填 `（原始檔無品名）`，條碼留空、配對方式為「待補」（因為沒有品名可以配對）。
- **目前有 2 個**：`266288`、`281429`。其中 266288 銷售金額不小（一天約 5 萬元）。
- **補資料方式**：直接在對照表填入正確的「品名」和「條碼」，重跑整理程式後就會套用；之後不會被覆蓋回 `（原始檔無品名）`。
- 這些品號的銷售照常輸出，Dashboard 也會顯示（品名為 `（原始檔無品名）`，條碼欄顯示「待補（康是美 品號）」）。

## 9. 程式會停下來的情況

| 情況 | 訊息重點 |
|---|---|
| `data/raw` 符合檔名的檔案不是剛好一個 | 列出找到的檔案 |
| 屈臣氏第 3 列欄位名稱和預期不同 | 列出實際欄位 |
| 康是美第 3 列找不到日期欄 | 找不到日期欄 |
| 康是美 A 欄出現未知指標 | 列出該指標文字 |
| 輸出檔被其他程式（如 Excel）開著 | 請先關掉該檔案 |
| 屈臣氏日期格式錯誤、找不到 `DailySaleExcel (2)` 工作表 | Python 錯誤訊息（未特別處理） |
