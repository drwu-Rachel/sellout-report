# Sell-out 週報

依序做完下面 4 步。全程用繁體中文回覆。

## 1. 整理最新資料

```
python scripts\clean_sellout.py
```

- 會讀 `data\raw` 裡每個通路的檔案（每個通路只能一個），更新 `data\processed\sellout_daily.csv` 和 Dashboard。
- 程式停下來時（欄位不符、同通路多個檔、CSV 被 Excel 開著）：把錯誤告訴使用者並停止，不要自己改 `data\raw` 裡的檔案。
- 記下印出的「問題列」摘要，第 4 步要提。

## 2. 計算週報數字

```
python scripts\weekly_report.py
```

程式會印出週報路徑（`output\週報_<本週最後一天>.md`）。所有數字都由程式計算，不要自己重算或改表格。規則：

- 一週＝週一到週日；各通路分開取資料中最近一個完整週當「本週」，前一週當「上週」。
- 兩通路的本週不同時（資料期間沒重疊），不加總、不直接比較金額，只比較各自的成長率。
- 康是美最後一天（資料不完整）排除。
- 品項依「金額增減」排名；有條碼用條碼，沒條碼用通路品號。

## 3. 寫 3 句重點結論

讀週報檔，把 `<!-- 重點結論 -->` 那一行換成剛好 3 句，用編號清單（`1.` `2.` `3.`）：

1. 各通路整體表現：金額、數量的成長率（寫出數字與期間）。
2. 最主要的成長來源：哪幾個品項、增加多少金額。
3. 最需要留意的衰退：哪幾個品項、減少多少，或其他值得追的現象。

寫法：
- 每句都要有表格裡的具體數字，金額用「萬元」四捨五入到小數 1 位（例：12.4 萬元）。
- 只寫表格看得出來的事實，不要猜原因（例如不要說「因為促銷」）；可以說「建議確認原因」。
- 品名可省略「DR.WU」前綴。
- 如果衰退品項是「原始檔無品名」或試用品、體驗包（品名以「88-33」或「試)」開頭），要點明，因為可能是資料問題而不是銷售問題。
- 不要改動其他段落。

## 4. 回報

告訴使用者：週報路徑、3 句結論、第 1 步的問題列摘要（有的話）。
週報含銷售資料，`output\` 不放進 Git，提醒不要上傳或分享到外部。
